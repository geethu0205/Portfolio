Object-Oriented Software Engineering

Java OOP Architecture & Core Modules

IntelliAC is designed with clean modularity, separation of concerns, and robust object-oriented patterns in Java.

ClassroomController.java

The central controller orchestrating sensor polling cycles, timetable schedules, and dispatching actuation commands to AC hardware.

public void evaluateClimate(Classroom c) {
  int count = c.getOccupancy();
  if (count == 0) enterStandby(c);
  else modulateLoad(c, count);
}

OccupancySensor.java

Interfaces with PIR and overhead vision counters, filtering noise and verifying consistent vacancy thresholds before triggering idle sleep.

public boolean isVacantForThreshold(int minutes) {
  return getLastPresenceDuration() > minutes;
}

ThermalOptimizer.java

Applies thermodynamic heat load calculations: combines ambient Chennai temperatures, glass insulation coefficients, and human metabolic thermal wattage.

double heatWatts = (headcount * 100.0) +
  ((outsideTemp - setpoint) * heatLossFactor);

EnergyAuditLogger.java

Maintains high-precision telemetry logs, computing exact kilowatt-hours saved, avoided peak electricity tariffs, and emissions offset.

public double calculateTotalSavings() {
  return (baselineKwh - actualKwh) * TARIFF_RATE;
}
